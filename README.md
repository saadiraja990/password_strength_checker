# Password Strength Checker 🔐

A simple Python project that checks the strength of a password based on its length, uppercase letters, lowercase letters, digits, and special characters.

## Features

* Checks password length.
* Detects uppercase and lowercase letters.
* Checks for numbers and special characters.
* Displays password strength as Weak, Medium, or Strong.
* Beginner-friendly Python code.

## Technologies Used

* Python 3
* String module
* Conditional statements
* Loops and functions

## How to Run

1. Clone this repository or download the Python file.
2. Open the project in VS Code or any Python IDE.
3. Run the following command:

```bash
python password_strength_checker.py
```

4. Enter a password when prompted.

## Sample Output

```text
Enter your password: Saad@1234
Password Strength: Strong
```

## Strength Criteria

| Score | Strength |
| ----- | -------- |
| 0–2   | Weak     |
| 3–4   | Medium   |
| 5     | Strong   |

The program checks five characteristics of the entered password.

## Project Purpose

This project was created to practice Python programming, conditional statements, and basic cybersecurity concepts. It is designed for beginners who want to understand how password strength checking works.
